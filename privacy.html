2. ข้อมูลที่เราเก็บ

2.1 ข้อมูลบัญชี

เมื่อสมัครหรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน ระบบยืนยันตัวตนของ Firebase Authentication จะจัดเก็บอีเมล รหัสผู้ใช้ (UID) และข้อมูลการยืนยันตัวตนที่จำเป็น เราไม่สามารถเห็นรหัสผ่านแบบข้อความธรรมดาได้ นอกจากนี้แอปอาจเก็บชื่อที่แสดง (display name) และเวลาที่สร้างหรือปรับปรุงโปรไฟล์ใน Cloud Firestore

หากผู้ใช้กรอกเบอร์มือถือตอนสมัคร (ไม่บังคับ) แอปจะเก็บเบอร์เป็นตัวเลข 9–10 หลักไว้ในโปรไฟล์ เพื่อใช้ยืนยันเจ้าของบัญชีก่อนลบบัญชีในแอป แอปไม่ส่ง SMS ไม่ใช้เบอร์เป็นวิธีเข้าสู่ระบบ และไม่ขอสิทธิ์อ่านเบอร์จากอุปกรณ์หรือรายชื่อผู้ติดต่อ

2.2 ข้อมูลลีดเดอร์บอร์ด

เมื่อผู้ใช้ที่เข้าสู่ระบบจบรอบเกมและมีคะแนนมากกว่าสถิติเดิม ระบบจะบันทึกข้อมูลต่อไปนี้

  • รหัสผู้ใช้ (UID) และชื่อที่แสดง
  • คะแนนสูงสุด ยุค และระดับความยากของบอร์ด
  • เวลาที่ทำคะแนนได้ (UTC)

คะแนนจะแสดงต่อผู้ใช้ที่เข้าสู่ระบบคนอื่นในลีดเดอร์บอร์ดของบอร์ดนั้น

2.3 ข้อมูลที่เก็บในเครื่อง

Token ทดลอง ประวัติ Token ความคืบหน้า สถิติ สกิน และการตั้งค่าบางรายการ ถูกเก็บในหน่วยความจำของอุปกรณ์ (SharedPreferences) และยังไม่ซิงก์ขึ้นคลาวด์ ข้อมูลส่วนนี้จะอยู่ในเครื่องจนกว่าผู้ใช้จะล้างข้อมูลแอปหรือถอนการติดตั้ง Token ในเวอร์ชันนี้เป็นข้อมูลทดลอง ไม่ใช่เงินจริง และไม่สามารถแลกของหรือเงินสดได้

2.4 ข้อมูลจากโฆษณา

แอป Android ใช้ Google AdMob เพื่อแสดงโฆษณาแบบให้รางวัล และใช้ Google User Messaging Platform (UMP) เพื่อขอความยินยอม SDK ของ Google อาจเก็บหรือประมวลผลข้อมูล เช่น ตัวระบุโฆษณาหรืออุปกรณ์ ที่อยู่ IP พื้นที่โดยประมาณ ข้อมูลการโต้ตอบกับโฆษณา และข้อมูลวินิจฉัย ตามนโยบายและความยินยอมที่ผู้ใช้ให้ไว้

ผู้ใช้สามารถตรวจหรือเปลี่ยนตัวเลือกความยินยอมได้ผ่านกลไกของ UMP ที่แอปแสดง และควรตรวจสอบการตั้งค่าโฆษณาของบัญชี Google ด้วย
